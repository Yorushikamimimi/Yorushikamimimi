# Yorushikamimimi

喜欢 Yorushika，也喜欢把日常的小麻烦做成顺手的工具。

这里放一些自己用的工具、AI / Agent 实验，以及因为喜欢而做的项目。有现成好用的就先用；遇到不顺手的地方，再试着改一改。

## 自己用，也分享给你

| 项目 | 做什么 |
|---|---|
| [docdoc](https://github.com/Yorushikamimimi/docdoc) | 让 Codex 局部修改 Word 文档，并检查有没有误改其他内容的 Skill 与 MCP |
| [system-mental-model](https://github.com/Yorushikamimimi/system-mental-model) | 从业务流程理解系统，再用实际回答、变式和证据检验理解的学习 Skill |
| [codex-thread-handoff](https://github.com/Yorushikamimimi/codex-thread-handoff) | 帮助长对话从文件恢复上下文，核对接手情况后继续工作 |
| [Sunge](https://github.com/Yorushikamimimi/Sunge) | 用 Markdown / Obsidian 保存个人记录和目标，让 AI 对话从文件接续上下文的非官方框架 |
| [ai-context-vault](https://github.com/Yorushikamimimi/ai-context-vault) | 给 Obsidian 和 AI 助手用的个人上下文档案模板，按任务提供必要信息 |

还有一个自用的 macOS **文件整理助手**：先预览、确认，再按类型整理文件，也可以撤销。仓库暂时保持私有，App 依赖本机 Python / Tk。

## 也做一些工程探索

| 项目 | 做什么 |
|---|---|
| [nautilus-clinic](https://github.com/Yorushikamimimi/nautilus-clinic) | 串联患者、处方发药和库存业务，探索权限、条件库存扣减与事务一致性 |
| [rag-nexus](https://github.com/Yorushikamimimi/rag-nexus) | Spring AI + pgvector 的全栈 RAG 原型，包含多源注入、向量召回、流式问答与来源展示 |
| [nautilus-media-cloud](https://github.com/Yorushikamimimi/nautilus-media-cloud) | 用 PostgreSQL `SKIP LOCKED` 分配异步任务，搭配 Spring Boot 控制面与 Python Worker |
| [My Knowledge Base](https://github.com/Yorushikamimimi/My-Knowledge-Base) | Java + Python 的本地 RAG 知识库工程，涵盖文档上传、向量入库、问答与来源展示 |

另有 **SlotFlow** 限量预约原型，探索 Agent 查询与草稿、用户确认、订单与库存事务，以及超时恢复。已做本地业务验证和隔离云端后端的小规模验证，供应商为模拟实现。

平时用 Java / Spring Boot 和 Python，也会碰 React、Vue、PostgreSQL、Docker、MCP 与 Agent Skills。

如果某个工具刚好帮到了你，或你发现哪里用着别扭，欢迎到对应仓库聊聊。
